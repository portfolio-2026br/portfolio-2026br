## Sobre

Este perfil no GitHub foca em experimentar e documentar soluções reais para engenharia de software: automação CI/CD,
indústria 4.0 empacotamento com Docker, segurança aplicada e otimização de desempenho (vetorização SIMD). Uso este
repositório como portfólio técnico.

**Construindo código confiável, pipelines eficientes e soluções práticas para problemas reais.** 🚀
